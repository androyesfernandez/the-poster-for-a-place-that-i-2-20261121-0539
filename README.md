A vintage travel poster for Solmara, a harbour town that does not exist, drawn entirely with PIL: a colossal natural stone arch strides across the bay with a lighthouse on its crown, and on late-summer evenings the setting sun drops exactly through the archway. The program renders the poster in flat shapes at twice size and reduces it, deterministically, to /output/entry.png (896×1024).

## Run it

```sh
python3 main.py
```

That writes the poster to `/output/entry.png` (896×1024 PNG). The program uses only the Python 3.13 standard library plus Pillow and always writes the same bytes.
